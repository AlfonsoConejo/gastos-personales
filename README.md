# Control de gastos personales

Con el control de gastos personales puedes llevar un registro de todos los gastos que haz realizado y mientras te mantienes dentro de tu presupuesto. Así, con cada nuevo gasto agregado, el sistema te muestra con una barra dinámica el presupuesto que te queda libre.

## Características
- **Tema**: cambia entre el tema claro y oscuro.
- **Guarda un presupuesto**: crea, edita y elimina todos los gastos que necesites. 
- **Validación de formularios**: evita que dejes campos vacíos o con valores inválidos.
- **Barra de presupuesto'**: la barra aumenta o reduce de tamaño al manipular los gastos.
- **Persistencia en LocalStorage**: tus configuraciones y sesiones se guardan aunque cierres el navegador.
- **Tabla de gastos**: visualiza todos los gatos agregados.
- **Ingreso de números al estilo bancario**: los números se van recorriendo de derecha a izquierda al momento de escribir montos, siempre comenzando con un $0.00.


## Retos y Aprendizajes
 - Tabla generada a partir de un arreglo
 - Diseño responsivo
- Envío de información mediante datasets
- Event listeners para controlar eventos
- Funciones para manejar arreglos de objetos
- Programación orientada a objetos
